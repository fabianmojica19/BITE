# BITE Burger House

Proyecto final de una página web de hamburguesas artesanales.

[Abrir la página de BITE](https://fabianmojica19.github.io/BITE/)

## Qué puedes hacer

- Explorar el menú de hamburguesas y consultar sus precios.
- Recibir una recomendación según tus preferencias y presupuesto.
- Enviar una consulta desde el formulario «Escríbenos».

El panel de administración permite iniciar sesión, leer las consultas
recibidas y marcarlas como atendidas.

## Tecnologías

HTML, CSS y JavaScript para la página, Supabase para el inicio de sesión
y el almacenamiento de consultas, y GitHub Pages para la publicación.
